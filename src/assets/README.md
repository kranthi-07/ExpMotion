# EXP MOTION - Vol. 01

Thank you for purchasing EXP MOTION Vol. 01! You now own the React source code for 5 premium, production-ready animated components. 

## 🚀 Quick Start Guide

These components are designed to be as frictionless as possible. You do not need to install a massive component library—just drop the raw files into your codebase.

### 1. Install Dependencies
All of our components rely on **Framer Motion** for physics-based animations, and **Lucide React** for icons. 
Run this in your terminal:
```bash
npm install framer-motion lucide-react
```

### 2. Add the Components
1. Create a `components/ui` folder (or whatever folder structure you prefer) in your Next.js or React project.
2. Drag and drop the `.tsx` files from this folder directly into your project.

### 3. Use Them
Simply import and render them anywhere in your app:
```tsx
import { MagneticButtonDemo } from "@/components/ui/MagneticButtonDemo";

export default function MyPage() {
  return (
    <div>
      <MagneticButtonDemo />
    </div>
  );
}
```

## 💡 Suggestions & Customization

- **Tailwind Colors:** All components use standard Tailwind CSS classes. To change the glowing colors, simply open the component file and change classes like `bg-purple-500` to your brand's color (e.g., `bg-orange-500`).
- **Dark Mode:** These components are optimized for dark-mode interfaces. The glowing gradients and glassmorphism `backdrop-blur` effects look best on black or dark gray backgrounds.
- **Physics Tweaks:** Inside the components, you will see `transition={{ type: "spring", stiffness: 300, damping: 20 }}`. Feel free to lower the `stiffness` for a "softer" animation, or increase it for a "snappier" feel!
