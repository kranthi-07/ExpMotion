# EXP MOTION - Component Source Code

Thank you for downloading from EXP MOTION! 
This package contains both the React (Next.js/Framer Motion) and Vanilla (HTML/CSS/JS) versions of the component.

## 📁 Directory Structure

### `/react`
Contains the `.tsx` file ready to be dropped into any Next.js or React project.
**Requirements:**
- Tailwind CSS
- Framer Motion (`npm install framer-motion`)
- Lucide React (optional, for icons)

### `/vanilla`
Contains the raw `index.html`, `style.css`, and `script.js` files.
**Usage:**
Simply open `index.html` in any web browser to view the component. You can copy the code directly into your WordPress, Shopify, or static HTML projects. No build tools required!
